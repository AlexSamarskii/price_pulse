# Внешнее воспроизведение

Пройденные локальные fixture-тесты не означают поддержку произвольной публичной
площадки. Live target и live LLM-провайдеры требуют отдельного операторского
одобрения.

## Публичная цель

Оператор утверждает цель, точный SourcePolicy, robots policy, лимиты и
обоснование. Для воспроизводимости фиксируются владелец/оператор, URL, policy
digest, версии runtime и broker, команда, время начала и окончания и bounded
outputs. Generated worker остаётся без сети; все внешние запросы идут через
отдельный egress broker.

Проверяются robots, hosts, paths, redirects, rate, concurrency, timeout, размер
ответа и job state. Результат не является основанием расширять allowlist или
изменять одобренную политику.

## Live провайдеры

Отдельно проверяются OpenAI-compatible API, native Anthropic и Ollama. Сценарии
включают valid output, invalid output, timeout и fallback. Evidence фиксирует
ответ, usage, сработавшие границы и отсутствие раскрытия credentials. Cookies,
Authorization, provider keys и профили не попадают в логи или artifacts.

## Проверка LIME

29 октября 2026 года выполнена ограниченная проверка публичной витрины
`https://limestore.com/ru_ru`, выбранной оператором. Просмотрены главная страница
и каталог `/ru_ru/catalog/women_new`. Для сбора использована одна карточка:
`/ru_ru/product/39003-4442_723_001_cernyi`.

Политика сбора разрешала только `limestore.com`, указанный путь карточки и
`/robots.txt`: не более одной страницы на захват, 6 запросов в минуту, один
одновременный запрос, timeout 15 секунд, валюта RUB. Полученный robots.txt
разрешал выбранные локализованные пути. Правило `/product*` относится к корневому
пути и не совпадает с `/ru_ru/product/...`. Запросы с query-параметрами,
авторизованные разделы, изображения и внешние API не использовались.

Всего выполнено 8 GET-запросов: четыре проверки robots.txt, главная страница,
каталог и два снимка карточки. Все ответы — HTTP 200; фактический максимум —
2 запроса за 60 секунд. Снимки карточки получены в 19:40:24 и 19:43:42 UTC.

Из очищенного HTML извлечён товар «Бархатная юбка-шорты с кружевом», чёрный цвет,
размеры XS, S, M и L. Цена каждого варианта — 4 999 RUB, онлайн-наличие
подтверждено в обоих снимках. Название, идентификатор, цвет и валюта получены
из JSON-LD; SKU, размеры, цены и онлайн-наличие — из соответствующего товара
в JSON-данных Nuxt. Цена и цвет сверены между двумя представлениями.
Для полей сохранены URL, время получения, digest захвата и указатель на источник.

Извлечение выполнено детерминированным кандидатом в контейнере без сети,
с read-only FS и непривилегированным пользователем. LLM не вызывалась.
Каждый захват встроен в собственную неизменяемую версию кандидата;
проверка не подтверждает готовность адаптера для регулярного сбора.

Сохранены один товар, четыре варианта и восемь наблюдений. Оба задания
завершились успешно. Проверены повторная запись без дублей, история через API,
CSV/JSON-экспорт и отсутствие ложных уведомлений. Dashboard вернул HTTP 200;
визуальная проверка браузером в этот прогон не входила.

Цена и наличие между снимками не изменились. Срабатывание уведомления на
реальном изменении, длительная работа по расписанию и реальные OpenAI,
Anthropic и Ollama endpoints остаются за пределами этой проверки.

## Проверка Ollama

29 октября 2026 года адаптер `OllamaProvider` выполнил один реальный вызов
`http://127.0.0.1:11434/api/generate` с моделью `qwen2.5:7b` (Q4_K_M).
Использован фрагмент JSON-LD из ранее очищенного захвата карточки LIME;
новых запросов к магазину не было. Ключи и авторизация не использовались.

Ответ получен с HTTP 200 за 36,4 секунды. Модель сообщила 780 входных и
311 выходных токенов при бюджете 4096, timeout 120 секунд и лимите одного
вызова. JSON прошёл общую схему адаптеров. Название, SKU, canonical URL,
цвет, валюта, наличие и provenance совпали с источником. Цена `4999.00`
после нормализации равна исходным `4999` RUB.

Модель оставила необязательный `product_id` пустым, хотя prompt запрашивал
его заполнение. Идентификация сохранена через проверенные canonical URL и SKU.
Первоначальный проверочный скрипт ошибочно требовал заполнить это поле и
сравнивал цены как строки. Исправлена только проверка результата по общему
контракту; исходный ответ сохранён, повторного обращения к модели не было.

Проверка подтверждает успешный путь native Ollama API и учёт токенов.
Live-сценарии некорректного ответа, timeout и fallback не выполнялись.
OpenAI и native Anthropic остаются непроверенными; общий внешний гейт
провайдеров остаётся открытым. Автоматическое чтение настроек провайдера
из конфигурационного файла в CLI этой проверкой не добавляется.

## Pending environment

`pending_environment` используется только для реального отсутствующего внешнего
компонента или операторского окружения. Обязательно указываются причина, точная
команда, которую невозможно выполнить, и ожидаемый наблюдаемый результат.
Отсутствующая реализация, тест, policy field или verifier является defect.

## Явные ограничения

This workflow does not provide universal store support, CAPTCHA solving,
credentials bypass, or access to authenticated content. It does not execute
generated code on the control plane. Do not bypass the challenge, broaden the
allowlist, raise the rate, or disable the hardened runtime. A rate or challenge
response enters a cooldown; repeated cooldowns end the job.
